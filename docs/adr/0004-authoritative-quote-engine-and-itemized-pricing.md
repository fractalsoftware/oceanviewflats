# Authoritative Quote Engine and All-Inclusive Itemized Pricing

Quote computation is centralized within a deep, authoritative backend Quote Engine that evaluates night-by-night seasonal rates, enforces strict multi-tier maximum minimum stays, applies property default base rates for unlisted dates, and itemizes mandatory Cleaning Fees into a single all-inclusive Settlement Currency (COP) figure. While the static frontend continues to provide instant date-picker previews using build-time JSON, all transactional settlement endpoints (`payment.php`, `book-request.php`) and the runtime `/api/quote.php` endpoint delegate exclusively to this pure in-process engine. This eliminates pricing drift across languages, prevents holiday minimum-stay circumvention, and guarantees that the customer's prospective price matches the exact settlement charge.
