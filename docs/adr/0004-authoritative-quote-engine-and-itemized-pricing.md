# Authoritative Quote Engine and All-Inclusive Itemized Pricing

Quote computation is centralized within a deep, authoritative backend Quote Engine that evaluates night-by-night seasonal rates from the relational database (`PdoRateSource` backed by the `property_rates` table, with automatic fallback to `CsvRateSource` and `PropertyRatesConfig` baseline rates for unpriced date gaps), enforces strict multi-tier maximum minimum stays, and itemizes mandatory Cleaning Fees into a single all-inclusive Settlement Currency (COP) figure. All transactional settlement endpoints (`payment.php`, `book-request.php`) and the runtime `/api/quote.php` endpoint (including active rate summary queries via `action=rates`) delegate exclusively to this database-backed engine, while Admin Console Seasonal Rate Tier mutations (`create`, `update`, `delete`, `seedFromCsv`) atomically synchronize `cache/prices.json`. This eliminates pricing drift across the Admin Console, public pages, and languages, prevents holiday minimum-stay circumvention, and guarantees that the customer's prospective price matches the exact settlement charge.
