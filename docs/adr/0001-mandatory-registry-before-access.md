# Mandatory Guest Registry Before Granting Access Credentials

Access Credentials and the Guest Guide are strictly withheld until the Primary Guest completes the Guest Registry for all staying Guests. While standard vacation rental workflows typically issue door codes immediately upon payment confirmation, OceanViewFlats requires complete identification details for all occupants prior to releasing property entry credentials in order to enforce compliance with Colombian statutory hospitality regulations and Playa Salguero condominium administration security clearance. Per [ADR 0012](0012-personal-data-protection-and-ley-1581-compliance.md), generated smart-lock Access Credentials (`0XXXXXX#`) are cryptographically random and never derived from a guest's government identification document or phone number.
